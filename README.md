# TRPG_design

这里是我们跑团（TRPG）相关设计与讨论的大本营，主要围绕《龙与地下城》第五版（2014 规则）。讨论与想法欢迎直接开 Issue 或 Pull Request。

> 仓库里的代码均由 Claude 编写，部分图像为 AI 生成；运行前请先看 [AI 使用声明 / AI Usage Notice](AI_NOTICE.md)。
>
> 版权：保留所有权利，仓库仅供浏览和学习，未经许可请勿复用；详见 [LICENSE](LICENSE)。

## 目录

按内容类型分类，每个作品在对应目录下有自己的子文件夹，具体说明见各子文件夹：

| 目录 | 内容 |
| --- | --- |
| [`scenes/`](scenes/) | 3D 场景（Blender 脚本、渲染图、动画） |
| [`html/`](html/) | 网页作品：可交互的小页面、工具等 |
| [`svg/`](svg/) | 矢量美术：地图、道具卡、图标等 |
| [`plots/`](plots/) | 图像与图表：角色立绘及其绘制过程、数据可视化等 |
| [`notes/`](notes/) | 文字资料：设定、规则速查、团务记录与讨论 |

## 现有作品

- [`scenes/homebase/`](scenes/homebase/)：法师小队的据点，Blender 剖面场景
- [`scenes/assets/`](scenes/assets/)：Blender 素材库，每个素材一段带参数的代码加一张缩略图
- [`scenes/blackstaff-office/`](scenes/blackstaff-office/)：深水城黑杖塔办事处内景，Blender 剖面场景
- [`scenes/shadow-base/`](scenes/shadow-base/)：the Shadow 小队在深水城的据点外景沙盘（木屋大厅、五人宿舍、篝火院子、葡萄架露台、魔法喷泉）
- [`scenes/weapons/`](scenes/weapons/)：高精度武器（宝石刺剑、藤蔓法杖、魔法鲁特琴）的展示渲染
- [`html/bard-lute/`](html/bard-lute/)：《林间夜曲》，吟游诗人弹鲁特琴的小网页；宣传短片的生成脚本在 [`video/`](html/bard-lute/video/)
- [`html/scribe-scroll/`](html/scribe-scroll/)：《烛堡抄卷》，法师希娜在烛堡书库抄写法术卷轴的打字小游戏
- [`plots/hina-lumi/`](plots/hina-lumi/)：希娜·露弥（Hina Lumi）的立绘与绘制过程（工具、提示词、迭代）
- [`plots/wolf-lion-stars/`](plots/wolf-lion-stars/)：狼与白狮星空背靠背插画，单图失败后改为拆图拼合，再转绘成版画风格
