# the Shadow 据点（外景）

冒险小队「the Shadow」在深水城的据点，用 `bpy` 程序化搭建的外景沙盘，风格沿用 [`homebase`](../homebase/)：石头底座、木骨灰泥墙、石板瓦屋顶。尺寸按米计，底座 14 × 12 米，默认是白天，也可以切成夜景。

- **大厅**（后方正中）：石砌墙基、木骨架，单片错缝的蓝灰石板瓦；门廊有两盏灯笼，门两侧挂着队旗，屋顶下有队徽。右侧山墙是烟囱，左侧堆着柴火，正面窗下有花箱，门前左右各一个花圃。
- **宿舍**（左侧，门朝院子）：五个人一人一间。每间一扇门一扇窗，门刷成该队员的颜色，配同色门牌（银点表示房号）、门垫和小灯笼，屋顶上每间一根烟囱管。
- **训练场**（右前方）：泥地上围着绳圈擂台，有三个草人、两个箭靶、兵器架、长凳、木桶、草垛和三支火把。
- **紫藤棚活动区**（右后角）：石板露台上的紫藤棚架，棚下一张长宴会桌，柱子间挂着小灯串；旁边一个倒扣的木桶当赌桌，上面有骰子、纸牌和赌注。
- **庭院**：篝火（三根原木长凳、三脚架吊锅）、水井、石板路；路旁和训练场上空是深水城的漂浮光球（driftglobe），跟黑杖塔场景用的是同一种。宿舍后面有橡树、松树、野花地和香草圃，紫藤棚旁有一棵紫叶枫，栅栏边种着开花的灌木。
- **围墙与大门**：后墙和左墙是尖头木栅，前面和右边是矮围栏。大门挂着「THE SHADOW」招牌和两面队旗。
- **队徽**：黑色日食，外面一圈银色日冕和光芒，一把匕首竖着穿过；旗帜用黑紫配色。

## 如何运行

本地配置 Blender 的方法见 [`scenes/ENVIRONMENT_SETUP.md`](../ENVIRONMENT_SETUP.md)；在 VM 的 Mac 上要加行内前缀，见 [`scenes/README.md`](../README.md)。

```bash
scenes/blender.sh scenes/shadow-base/build_scene.py --render out/wide.png --shot wide
```

常用参数：

- `--shot wide|close|top|pergola`：全景 / 训练场望向大厅的平视近景 / 正交俯视 / 从右侧围栏外看进紫藤棚
- `--time day|night`：白天（默认）或夜景（月光、紫色轮廓光、窗户和灯点亮）
- `--samples N`：渲染采样数（默认 64）
- `--res 百分比`：渲染分辨率百分比
- `--save out.blend`：保存为 `.blend` 文件

物件比 homebase 多，`--samples 12 --res 50` 的预览在 VM 的 Mac 上大约要 3 分钟。
