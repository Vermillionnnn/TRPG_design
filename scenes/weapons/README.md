## 三件武器

- **宝石刺剑**（[`gem_rapier`](../assets/gem_rapier.py)）：照设计者提供的角色图和握剑细节图做。剑柄先画了一张正视示意图 [`rapier_hilt_sketch.svg`](rapier_hilt_sketch.svg)（单位毫米），叠在参考图上逐处对齐后再建模，模型的尺寸直接取自这张图。
  - 剑身：宽 3.6 厘米，近乎无色的透明水晶，截面是压扁的六边形，切面平整，带薄膜干涉和色散；晶体深处散落着几百颗蓝、青、粉、橙、绿、紫的小光点：每颗是一个饱和的小亮芯，外面罩一圈向外渐淡的柔光晕；光点只分布在剑身中间一圈椭圆截面里（相当于一层遮罩），离玻璃表面留有距离，看起来是嵌在晶体里面而不是贴在表面。颜色饱和、亮度适中，渲染时不容易发白。剑身往剑尖方向收窄约 35%，末端还留有根部 65% 的宽度，最后用一个短三角尖收尾，不是一路细到尖。剑根是一段同样带光点的水晶座：花瓶形张开到尖锐的肩，收腰，再鼓成一颗菱形接进剑身，立在一圈很薄的金环上。
  - 护手：厚重的金件，宽 14.2 厘米、高 4.1 厘米，完全对称。上半是较窄的平顶，两侧向外鼓着弯下去，到一圈锋利的圆边；下半从圆边斜着直接收到握柄顶，没有单独的细颈。
  - 握柄：一整根金柄，顶端几道缠线，缠线以下刻着八道圆底的纵向凹槽，两头渐浅消失；紧贴护手处半径 1.5 厘米，往下胀到 2.3 厘米，再一路收细到剑首处的 1.3 厘米。
  - 护指弓：一条扁金带，上沿接着护手上半的弧线往外延伸，远远伸到右边，再斜着收回，一路收细；离握柄还有一段时又慢慢变宽，到和握柄下段相接处最宽（约 1.3 厘米），和握柄连在一起，然后绕过底部卷成一个逐渐收紧的小圈。
  - 剑首（配重）：两道串珠的金箍下面是一个带竖槽的梨形金球，最宽处一圈腰带上嵌六颗小蓝宝石；再往下是金萼托，六根金爪围成笼子，笼里关着一颗和剑身同材质、带光点的八面水晶坠，金爪在最下端收拢到一个车削的小金尖上。参考图里剑首只是两段几何菱形，建模时换成了这种有实际结构的样子。
  - 全长约 2.31 米，其中剑柄（护手顶到剑首尖）约 50 厘米，剑身（水晶座以上）约 1.69 米。
- **藤蔓法杖**（[`vine_staff`](../assets/vine_staff.py)）：微微弯曲、带树瘤的深色木杖，越往上越粗。杖顶鼓成一个木杯，蓝色六棱水晶的下半截嵌在杯里，杯沿冒出三片小碎晶。木杯外侧长出五根卷须，远远绕开水晶向外鼓起，再在水晶尖上方收拢卷回。三条藤蔓各不相同：一条粗的主藤从中段绕上来，越往上叶子越密，开着发蓝光的花苞，最后爬进杖头；一条细的木质老藤在下半截绕得很紧，只有稀疏的小叶，末端卷离杖身；一条嫩绿的短藤在上段松松绕一圈。木杯下有一圈叶子。杖身约 1.55 米，加杖头约 1.85 米。
- **魔法鲁特琴**（[`magic_lute`](../assets/magic_lute.py)）：梨形琴身，背面是深浅交替的 11 条木板；云杉面板，金色镶边。音孔是一圈发光的符文玫瑰窗（六芒星、内圈光环、外圈符文点，金色外环）。琴颈上有金色品丝，琴头向后折，两侧插着琴轸，末端是金托上的一颗蓝水晶。六根琴弦发青光，旁边飘着几个发光的音符。琴身长 0.48 米。

三件统一用参考图里的配色：白、金、深蓝和水晶蓝。

## 用法

本地配置 Blender 的方法见 [`scenes/ENVIRONMENT_SETUP.md`](../ENVIRONMENT_SETUP.md)。

```bash
scenes/blender.sh scenes/weapons/build_scene.py --render out/weapons.png --shot all
```

参数：

- `--shot all|rapier|staff|lute`：三件合影 / 刺剑护手特写 / 法杖杖头特写 / 鲁特琴
- `--samples N`：渲染采样数（默认 128）
- `--res 百分比`：渲染分辨率百分比（合影 1600×1200，特写 1000×1200）
- `--save out.blend`：保存为 `.blend` 文件

### 刺剑单独展示

`rapier_scene.py` 把刺剑单独拿出来横放：剑尖朝右，护指弓垂在下面，悬在酒红色背景前（中间一团稍亮，四周暗到近黑）。打光是偏暖的一组长条柔光箱，沿剑身方向摆、和剑一样长：一条暖白的在上方给金件和玻璃拉出一道干净的高光，琥珀色和玫瑰色两条在背后勾出剑身边缘，一条在前下方补暖光，再加一盏琥珀色小聚光灯照剑柄。

```bash
scenes/blender.sh scenes/weapons/rapier_scene.py --render out/rapier.png --shot full
```

- `--shot full|hilt|pommel`：整把剑（2400×1000）/ 剑柄特写（2400×1500）/ 剑首（1200×1000）
- `--length 米`：剑的全长（默认用素材的默认值），镜头和灯光会跟着长度调整，用来比较不同剑身长度
- `--samples`、`--res`、`--save` 同上

在其他场景里使用：

```python
from assets import gem_rapier, magic_lute, vine_staff

r = gem_rapier.build("Rapier", loc=(0, 0, 2.31))
r.rotation_euler = (math.radians(180), 0, 0)          # 剑尖朝下
vine_staff.build("Staff", loc=(1, 0, 0), tendrils=4, crystal_color="arcane_purple")
magic_lute.build("Lute", loc=(2, 0, 0), notes=0, glow=(1.0, 0.6, 0.2))   # 不要音符，琴弦发暖光
```

各素材的参数见 [`scenes/assets/README.md`](../assets/README.md)。

| `weapons_rapier.png` | 刺剑护手特写（1000×1200） |
| `weapons_staff.png` | 法杖杖头特写（1000×1200） |
