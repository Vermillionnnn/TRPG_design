# 黑杖塔办事处

深水城黑杖塔里「黑杖」的办事处内景，用 `bpy` 程序化搭建的剖面场景，风格与 [`homebase`](../homebase/) 统一。石、木、灰泥用的是同一套材质参数，同样是木骨灰泥墙、木地板和外露的椽子。房间是塔内圆厅靠里的半圆形办公区，直径约 10 米，前面沿直径切开，方便看清内部。

场景内容：

- 墙下半截是一块块垒起的黑色玄武岩，对应黑杖塔的黑石；上半截是木骨灰泥墙，有斜撑和椽子。地面是带木钉的橡木窄板，外圈压着石砌边沿。
- 正中是一张厚重的橡木书桌，两侧是抽屉柜。桌上有账册、文件、墨水瓶和羽毛笔、火漆印章、沙漏、烛台、水晶球和头骨；高背座椅雕花：车削的腿和顶饰，靠垫上有拉扣，椅背顶上嵌着紫色宝石。黑杖靠在桌边。
- 桌前两把访客椅和一块圆地毯。
- 座椅后面是一扇尖拱窗，石砌窗框，菱格铅条玻璃，透进月光。塔从外面看没有窗，这扇是魔法窗。
- 窗右侧和左端各有一组弧形书架，带底座、顶部檐线和中间隔板，书脊上有金线。
- 窗左侧是石砌壁炉：炉口用楔形石块砌成平拱，中间嵌一块黑色拱心石。壁炉台下有木托架，上方的烟囱墙一块块垒起，挂着第一代黑杖的肖像。
- 右侧是房间的门：圆头橡木板门，装铁质带状合页、门环和锁板，嵌在木门框里，门楣上刻着黑杖的标记，门边有一盏壁挂烛台。
- 门旁边是存放卷宗和令状的格子柜，带抽屉和铜标签框；前面是摆着深水城地图的圆桌，上方浮着城市幻影。
- 左端是通往上层的石砌螺旋楼梯。
- 头顶是一盏挂在椽子上的铁环蜡烛吊灯。
- 屋里有薄雾。

## 如何运行

本地配置 Blender 的方法见 [`scenes/ENVIRONMENT_SETUP.md`](../ENVIRONMENT_SETUP.md)。

```bash
scenes/blender.sh scenes/blackstaff-office/build_scene.py --render out/wide.png --shot wide
```

常用参数：

- `--shot wide|close|top`：全景 / 办公桌特写 / 正交俯视
- `--samples N`：渲染采样数（默认 128）
- `--res 百分比`：渲染分辨率百分比
- `--save out.blend`：保存为 `.blend` 文件
